# Отчёт по лабораторной работе №8: Асинхронное программирование

## Описание
Асинхронный uptime-монитор сайтов. Скрипт читает список сайтов из `sites.csv`, проверяет их доступность через `aiohttp` каждые 10 секунд и логирует изменения статуса.

## Как запустить
1. Установить зависимости: `pip install aiohttp`
2. Запустить скрипт: `python monitor.py`

## Как это работает
- Список сайтов читается из CSV-файла (`sites.csv`).
- Каждые N секунд (по умолчанию 10) создаются задачи для проверки всех сайтов одновременно через `asyncio.gather`.
- Каждый запрос выполняется асинхронно, поэтому долгий ответ от одного сайта не блокирует проверку остальных.
- Если статус сайта изменился (например, с 200 на None), в лог пишется ALERT.

## Файлы
- `monitor.py` — основной скрипт с асинхронной логикой.
- `sites.csv` — список сайтов для проверки.
- `monitor.log` — файл с логами работы (создаётся автоматически).
