# Лабораторная работа №4 — Рефакторинг

## Исходный проект

Для рефакторинга использован собственный парсер книг из лабораторной
работы №3:

https://github.com/Dun4uv/prog-instruments-labs/tree/lab3/lab_3/books_parser

Программа извлекает данные из сохранённой страницы учебного сайта
https://books.toscrape.com/ и записывает их в CSV.

Исходная версия скопирована в каталог этой лабораторной и зафиксирована
отдельным коммитом до начала изменений.

## Выполненные изменения

| Проблема исходного кода | Изменение | Результат |
| --- | --- | --- |
| Разбор HTML, запись CSV и запуск находились в одном модуле | Код разделён на parser.py, storage.py и main.py | У каждого модуля отдельная ответственность |
| Большая функция parse_book обрабатывала все поля | Выделены функции извлечения названия и ссылки, цены, рейтинга и наличия | Логику отдельного поля можно читать и изменять отдельно |
| Повторялись поиск регулярным выражением и проверка совпадения | Введена функция _required_match | Проверка обязательного совпадения реализована в одном месте |
| Повторялась очистка HTML-сущностей и пробелов | Введена функция _normalize_text | Название и наличие обрабатываются общей функцией |
| Номер карточки добавлялся в каждом сообщении об ошибке | Формирование контекста ошибки перенесено в parse_book | Вспомогательные функции отвечают только за свои поля |

Использованы выделение функций, перенос функций между модулями
и устранение дублирования.

## Структура проекта

- main.py — запуск программы, обработка ошибок и вывод результата.
- parser.py — извлечение и проверка данных из HTML.
- storage.py — сохранение данных в CSV.
- test_main.py — существующие автоматические тесты.
- catalogue.html — сохранённая страница с 20 книгами.
- sample.html — небольшой пример с двумя карточками.
- books.csv — результат обработки каталога.
- requirements.txt — указание на использование стандартной библиотеки.

## Сохранение поведения

Сохранены правила разбора HTML, состав и порядок столбцов CSV,
кодировка UTF-8 с BOM, сообщения об ошибках и коды завершения.

Цена сохраняется строкой с двумя знаками после точки.
Ссылки преобразуются в полные адреса, рейтинг — в число от 1 до 5.
При ошибке разбора входных данных предыдущий CSV не перезаписывается.

Функции parse_book, parse_books и save_books остаются доступны
через модуль main для совместимости с прежним интерфейсом.

## Запуск

Требуется Python 3.10 или новее.

Из корня репозитория:

```bash
py lab_4/books_parser/main.py
```

Программа читает catalogue.html и записывает books.csv
в каталоге books_parser.

## Проверка

Из корня репозитория:

```bash
py -m unittest discover -s lab_4/books_parser -v
```

Все 7 существующих тестов прошли до рефакторинга, после разделения
модулей и после выделения вспомогательных функций.

Проверки охватывают извлечение полей, обработку HTML-сущностей,
запись CSV, некорректные карточки, отсутствие входного файла
и сохранность предыдущего результата при ошибке разбора.
