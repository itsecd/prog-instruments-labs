# Лабораторная работа №3: каталог книг из HTML

Собственный вариант: извлечь данные о книгах из сохранённой HTML-страницы
с помощью нескольких регулярных выражений и записать результат в CSV.

Источник данных — [Books to Scrape](https://books.toscrape.com/), учебный
сайт для практики сбора данных. Цены и рейтинги на нём демонстрационные.

## Файлы и исходные данные

- `main.py` — программа на стандартной библиотеке Python.
- `catalogue.html` — исходный HTML главной страницы, сохранённый
  пользователем 24 октября 2026 года. Содержит 20 карточек.
- `sample.html` — учебный пример из двух копий первой карточки.
  Во второй копии вручную изменены цена на 8.50, рейтинг на Five и наличие
  на In stock (5 available). Это тестовые значения.
- `books.csv` — результат обработки сохранённого каталога.
- `test_main.py` — проверки примеров, ошибок входа и формата CSV.

HTML хранится локально. Программа обрабатывает одну сохранённую страницу.
Для обновления исходных данных нужно открыть главную страницу сайта,
скопировать её исходный код через Ctrl+U и сохранить его в
`catalogue.html` в UTF-8.

## Запуск

Требуется Python 3.10 или новее. Проверено на Python 3.13.3.
Дополнительные пакеты не нужны.

Из этой папки в Windows:

```bat
py main.py
```

Из корня репозитория:

```bat
py lab_3/books_parser/main.py
```

Пути к входному HTML и выходному CSV определяются относительно самого
`main.py`, поэтому запуск не зависит от текущей папки терминала.
Повторный успешный запуск перезаписывает `books.csv`.

Ожидаемый результат для приложенного каталога — 20 записей.

## Регулярные выражения

Всего используются пять выражений:

| Данные | Как работает выражение |
| --- | --- |
| Карточки | `<article class="product_pod">(.*?)</article>` с флагом DOTALL; ленивое повторение выделяет карточки по отдельности. |
| Название и ссылка | Поиск ссылки внутри `<h3>`; две группы `([^"]+)` извлекают значения атрибутов href и title. |
| Цена и валюта | Первая группа извлекает £, вторая — число по шаблону `[0-9]+\.[0-9]{2}`. |
| Рейтинг | Альтернация между One, Two, Three, Four и Five; словарь преобразует слово в число. |
| Наличие | Пропускаются тег значка и пробельные символы; группа `([^<]+?)` извлекает текст. |

`parse_book()` разбирает одну карточку, а `parse_books()` выделяет
карточки и собирает список книг. `save_books()` записывает CSV.
`main()` отвечает за чтение файла, вызов этих функций и сообщения.

HTML-коды символов декодируются после извлечения полей через
`html.unescape()`. Пробелы в текстовых полях нормализуются.
Относительная ссылка преобразуется в полный URL через
`urllib.parse.urljoin()` с базовым адресом главной страницы.

## Результат и ограничения

Поля CSV: `title,price,currency,rating,availability,url`.
Цена сохраняется строкой с двумя цифрами после точки, рейтинг —
целым числом от 1 до 5 до сериализации. Кодировка CSV — UTF-8 с BOM,
разделитель — запятая. Кавычки и запятые внутри названий обрабатывает
`csv.DictWriter`.

Выражения рассчитаны на разметку приложенной главной страницы:
двойные кавычки, показанный порядок атрибутов и класс
`instock availability`. Это обработчик конкретного формата HTML.
Для другой разметки потребуется скорректировать выражения и базовый URL.

Если карточек нет или в карточке отсутствует допустимое обязательное поле,
программа сообщает причину ошибки и номер карточки, когда он известен.
Разбор всей страницы завершается до открытия CSV для записи, поэтому ошибка
разбора сохраняет предыдущий результат. Ошибки чтения, кодировки и записи
выводятся в stderr; код завершения при ошибке — 1, при успехе — 0.

## Проверки

Из этой папки:

```bat
py -m unittest -v
```

Из корня репозитория:

```bat
py -m unittest discover -s lab_3/books_parser -v
```

Проверяются две учебные карточки, полный каталог, HTML-коды символов,
названия с запятыми и кавычками после записи и чтения CSV, некорректные
обязательные поля и сохранность предыдущего CSV при ошибке разбора.

Для этого собственного варианта контрольная сумма из задания на валидацию
персонального CSV не вычисляется.
