

## Что исправлено (по коммитам)

| № | Коммит | Проблема («запах кода») | Исправление |
|---|---|---|---|
| 1 | Вынос магических строк в константы | Строки ("Love", "Fifteen", "Deuce") разбросаны по всему методу `score()`. | Вынесены в константы класса (`SCORE_NAMES`, `DEUCE`, `ADVANTAGE`). |
| 2 | Извлечение метода `_get_score_name` | 8 одинаковых цепочек `if` для перевода числа в название очка  | Создан метод `_get_score_name()`, инкапсулирующий логику перевода. |
| 3 | Декомпозиция метода `score` | Метод `score()` занимает ~60 строк (Long Method), переменная `result` перезаписывается 8 раз. | Метод разбит на `_is_deuce()`, `_is_advantage()`, `_is_win()`. Внедрен ранний возврат (early return). |
| 4 | Убран хардкод имени игрока | В `won_point` было захардкожено имя `"player1"`, класс работал только с дефолтными именами. | Имена игроков теперь берутся из полей класса (`self.player1_name`). |
| 5 | Замена циклов на прямое сложение | В `set_p1_score` использовался неэффективный цикл `for` для прибавления очков. | Заменено на прямое сложение (`+=`), что оптимизирует работу метода. |
