# Исходный код и тесты

Для ЛР №6 я взял программу проверки анкет из репозитория
`Autom4k/prog-instruments-labs`. Копия лицензии MIT лежит
в `ORIGINAL_LICENSE`. [Исходник на фиксированном коммите](https://github.com/Autom4k/prog-instruments-labs/blob/31db1f33ac0c2ee8973537abf317a1e29ce76aee/lab_1/lab1_var18.py).

В работе семь тестовых функций. Они проверяют, как программа
разбирает анкеты и отбирает те, в которых указан неверный номер.
Есть проверки чтения файла и сохранения результата.

Параметризованный тест проверяет формат номера на семи наборах
данных. В отдельном тесте `monkeypatch` подменяет чтение файла
и имитирует отказ в доступе.

Установите зависимости из `lab_6/requirements.txt` и выполните
команду из корня репозитория.

```bash
python -m pytest lab_6 -q
```
