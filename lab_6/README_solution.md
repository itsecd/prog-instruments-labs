# Лабораторная работа №6 — Unit tests

## Исходный проект

В основе — модуль `micrograd/engine.py` Андрея Карпаты (Andrej Karpathy), который реализует автоматическое дифференцирование скалярных выражений на графе вычислений. Исходник: https://github.com/karpathy/micrograd/blob/master/micrograd/engine.py. Автор и лицензия сохранены в `LICENSE_MICROGRAD`. В `micrograd_lab/engine.py` находится адаптация модуля с аннотациями типов, сохранённой логикой арифметических операций и обратного распространения градиента.

## Что сделано

Создано **15 отдельных тестовых функций** с использованием только pytest (без unittest test runner). Они проверяют конструктор, сложение, умножение, вычитание, деление, возведение в степень, обработку ошибочного аргумента, обратные арифметические операции, `repr`, вычисление градиентов, повторное использование узлов, ReLU, изоляцию графов и правило цепочки.

Усложнённые тесты:
1. `test_relu_cases` — параметризация `@pytest.mark.parametrize`: пять вариантов, включая окрестность нуля и граничное значение ноль.
2. `test_backward_invokes_each_unique_graph_node_once` — `monkeypatch` и `unittest.mock.Mock` как шпион за вызовами внутреннего обработчика, проверяющий уникальность обработки общего узла. `Mock` служит имитацией/наблюдением, сами тесты выполняются **pytest**.
3. `test_power_gradients` — дополнительная параметризация для разных степеней.

По правилам преподавателя **15 тестовых функций считаются 15 тестами**, даже если параметризованные варианты запускаются дополнительно.

## Как запустить

Из корня форка `prog-instruments-labs`:

```powershell
python -m pip install -r lab_6/requirements.txt
python -m pytest -q
python -m coverage run --source=lab_6.micrograd_lab -m pytest
python -m coverage report -m
```

Стандартный workflow преподавателя запускает `coverage run -m pytest` и `coverage report` из корня. При открытии PR в исходный репозиторий должен запуститься workflow `Unit testing for lab 6`.
