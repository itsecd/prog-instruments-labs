## Цель

На примере существующего типа приложения (файловый органайзер) показать настройку послойных конфигураций YAML и переключение окружений без изменения кода.

## Что делает приложение

Сортирует файлы из входного каталога по расширениям в подкаталоги `documents`, `images`, `code` и `other`. Управляемые настройки: исходный каталог, каталог назначения, категории расширений, безопасный тестовый режим, политика конфликтов имён и уровень логирования.

## Послойная конфигурация

- `config/base.yaml` — общий слой: пути, группы расширений и значения по умолчанию;
- `config/dev.yaml` — переопределяет `dry_run: true` и `logging.level: DEBUG`, позволяет безопасно посмотреть запланированные действия;
- `config/prod.yaml` — переопределяет `dry_run: false`, политику конфликтов `rename`, уровень логирования `INFO`.

Порядок приоритета: **base.yaml → dev.yaml / prod.yaml**. Алгоритм `merge_config` рекурсивно объединяет словари, сохраняет общие настройки и заменяет только параметры, определённые во втором слое. Конфиги разбираются `yaml.safe_load`; перед обработкой файлов выполняется проверка структуры и значений.

## Структура

```text
lab_9/
  README.md                 # методичка преподавателя (сохраняется)
  README_solution.md        # описание выполненной ЛР
  requirements.txt
  config/
    base.yaml
    dev.yaml
    prod.yaml
  organizer/
    __init__.py
    config.py               # загрузка, слияние, валидация
    app.py                  # приложение и CLI
  tests/
    test_config.py
```

## Запуск из корня форка

```powershell
python -m pip install -r lab_9/requirements.txt
python -m pytest lab_9/tests -q
python -m lab_9.organizer.app --env dev
```

По умолчанию приложение ищет `lab_9/demo/inbox` и планирует перенос файлов без изменений на диске. Для демонстрации создайте папку `lab_9/demo/inbox` с произвольным `.txt` или `.png` файлом. После запуска `--env dev` файлы останутся на месте. Запуск `--env prod` реально перемещает файлы в `lab_9/demo/organized`. **Не используйте prod на важных файлах:** приложение изменяет расположение файлов.
