# Профайлинг и оптимизация производительности (`main.py`)

## 1. Методика и инструменты
Для поиска узких мест использовались инструменты:
* **cProfile** + **pstats** — профилирование времени выполнения функций и количества вызовов;
* **tracemalloc** — замер пикового потребления оперативной памяти;
* тестовый набор данных на **200 000 анкет** (**sample_profiles.txt**).

## 2. Выявленные узкие места («ДО»)
1. **Избыточный парсинг полей и нескомпилированные регулярные выражения (CPU):**
   На функцию `process_profiles()` приходилось `2.171 с` из `2.358 с` общего времени работы (**92.1%**). Внутри неё `parse_profile()` для каждой из 200 000 анкет выполняла 6 вызовов `re.search` (всего `1 400 000` вызовов `re.search` и `re._compile` с учётом `is_21st_century()`), затрачивая `1.769 с`, хотя при фильтрации использовалось только поле `Дата рождения:`.
2. **Загрузка всего файла и всех списков в оперативную память (RAM):**
   `read_file()` считывал весь файл одной строкой, `re.split()` создавал вторую копию всех анкет в виде `list[str]`, а `process_profiles()` накапливал третий список подходящих анкет. Пиковое потребление RAM достигало **162.86 MiB**.

## 3. Внесённые оптимизации («ПОСЛЕ»)
1. **Потоковая обработка данных ($O(1)$ по памяти):** реализован генератор `iter_profiles()`, читающий файл блоками по 256 КиБ, и потоковая запись подходящих анкет в выходной файл без накопления списков в памяти.
2. **Предкомпиляция регулярных выражений и целевой поиск:** регулярные выражения вынесены на уровень модуля (`re.compile`), а поиск даты рождения и извлечение года объединены в один вызов `BIRTH_YEAR_RE.search()`.
