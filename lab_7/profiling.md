# Профилирование и оптимизация

Для лабораторной работы использована программа сортировки
анкет по фамилии и имени.

Профилирование выполнено с помощью стандартного модуля
Python `cProfile`.

## Обнаруженное узкое место

Основное время выполнения занимала функция `parse_data()`.

При обработке 20 000 анкет `re.search()` вызывалась
40 000 раз для поиска имени и фамилии.

## Оптимизация

Регулярные выражения вынесены за пределы цикла
и предварительно компилируются через `re.compile()`.

Также запись данных в файл изменена с `write()`
на `writelines()`.

## Результаты

| Показатель | До | После(ср.) |
|---|---|---|
| Общее время | 0.106 с | 0.083 с |
| parse_data() | 0.085 с | 0.0618 с |
| Вызовы функций | 424906 | 304914 |

В среднем время выполнения сократилось
на 27.3%.

Полные результаты профилирования находятся
в файлах `profile_result_before.txt` и `profile_result_after_*.txt`.
