# Проверки качества для утилит матриц

Морозов Данил Вячеславович, 6311-100503D

Исходный проект содержит генератор входных матриц и скрипт, который сравнивает результат C++ программы с произведением, вычисленным NumPy. [Исходники](https://github.com/Danilaooyey/parallel-programming/tree/4148e5b697d89647979f0f41df97416f973d09aa/lab1).

Из корня репозитория в активном окружении Python 3.14

```sh
python -m pip install -r lab_1/requirements.txt
make -C lab_1 fullcheck
make -C lab_1 precommit
```

Команда `make -C lab_1 format` форматирует код. Таргеты `lint`, `format-check` и `typecheck` запускают проверки по отдельности. Перед коммитом Ruff проверяет стиль и форматирование, а перед отправкой дополнительно запускается Pyright. В исходном проекте автоматических тестов не было.

Проверки GitHub Actions запускаются при открытии или обновлении PR с изменениями в `lab_1`.
