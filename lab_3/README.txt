ЛАБОРАТОРНАЯ РАБОТА № 3 — REGULAR EXPRESSIONS
Вариант 16

Состав проекта:
- main.py — проверка CSV регулярными выражениями и расчёт контрольной суммы.
- data/16.csv — исходный файл варианта 16.
- checksum.py — модуль преподавателя с алгоритмом контрольной суммы.
- result.json — результат для проверки GitHub Actions.
- validation_report.json — подробный отчёт о локальной проверке.

Запуск в VS Code (терминал PowerShell):
1. Откройте папку lab3_variant16.
2. Выполните команду:
   python main.py

Сторонние библиотеки не требуются — используются стандартные модули Python.

Важно:
- CSV читается в кодировке UTF-16, разделитель столбцов — точка с запятой.
- Нумерация строк для контрольной суммы начинается с 0: первая строка данных имеет номер 0.
- result.json содержит номер варианта и контрольную сумму.
- После запуска main.py файлы result.json и validation_report.json обновляются.

Ожидаемый результат локальной проверки:
- 10000 строк;
- 10 столбцов;
- по 100 невалидных значений в каждом столбце;
- 1000 уникальных строк с ошибками.
