# Валидация CSV, вариант 17

Морозов Данил Вячеславович, 6311-100503D

Запуск из корня репозитория

```sh
python lab_3/validate.py
```

Скрипт читает `17.csv` в UTF-16 с разделителем `;`. Для каждого из десяти столбцов задано регулярное выражение. Заголовок определяет порядок проверки полей. Строка попадает в список ошибок один раз, даже если у неё несколько невалидных полей. Нумерация записей начинается с нуля после заголовка.

Контрольную сумму вычисляет функция `calculate_checksum` из шаблона курса. Скрипт записывает вариант и сумму в `result.json`.
