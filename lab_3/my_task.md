В рамках лабораторной работы я написала скрипт для извлечения данных из HTML-страницы онлайн-библиотеки.

Скрипт использует несколько регулярных выражений для поиска и извлечения информации о книгах:
- Название книги
- Автор
- Год издания
- Цена (в рублях)

Валидные данные сохраняются в формате CSV для дальнейшего анализа.
