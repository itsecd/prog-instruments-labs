# Программа

Для выполнения лабораторной работы была использована 
программа-анализатор средней яркости трех цветовых каналов

# Узкое место

Основное время действия программы занимала функция 'distribution_brightness_columns'

# Оптимизация

Была произведена оптимизация. Функции 'cv2.imread' и 'cv2.split' были удалены.
В 'distribution_brightness_columns' были использованы потоки, для максимального ускорения работы функции

# Результат

Общее время работы программы сократилось с 8.050с до 2.532с
